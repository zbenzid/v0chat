# Mythes à ne jamais utiliser comme argument

Si l'utilisateur ou un script s'appuie sur l'un d'eux, le signaler calmement et revenir à ce qui est établi.

| Affirmation | Statut | Ce qu'il faut dire à la place |
|---|---|---|
| « Un envoi vaut 3 à 5 likes » (ou 15×) | Aucune source primaire | Les envois sont l'un des trois signaux officiels, sans poids publié |
| Premier lot de 200-500 vues, paliers TikTok chiffrés | Mythe (explications Douyin non sourcées) | Test sur un petit public de taille non publiée |
| Seuil de 70 % de complétion sur TikTok US | Non vérifié | La complétion est un signal fort, sans seuil public |
| Les hashtags augmentent le reach | Démenti (Mosseri) | Ils servent à la recherche ; 5 max |
| Il existe une meilleure heure de publication | Démenti sur Shorts, études contradictoires ailleurs | Publier quand son audience est là, juger à 72 h |
| La première heure décide de tout | Non étayé | Corrélation forte, pas déterminisme ; 65 % des vues en 3 jours |
| Modifier la légende ou supprimer un post pénalise | Démenti ou non étayé | Mais supprimer-republier sur Shorts peut passer pour du spam |
| Le contenu sponsorisé est rétrogradé | Démenti | Il doit en revanche être signalé (loi) |
| Un skip rate « bon » est sous 20 % | Contredit par la mesure (moyenne 60-65 %) | Comparer à la médiane du compte |
| « 85 % regardent sans le son », « 71 % décident en 3 s » | Anciens ou introuvables | Concevoir pour une compréhension sans le son, sans chiffre |
| Profils visuel/auditif/kinesthésique, regard et mensonge, commandes embarquées | Pseudoscience (PNL) | Langage concret, sensoriel, « tu », CTA explicite |
| L'IA est pénalisée en tant que telle | Démenti | C'est le contenu répétitif, non original ou non étiqueté (personas) qui est visé |
| « Plafond des 200 vues » formel | Plateau fréquent, aucun plafond attesté | Un compte de 1 000-5 000 abonnés touche ~10 % de ses abonnés par Reel |
| Un filigrane coûte 90 % du reach | Chiffre sans source | La pénalité existe (Instagram, TikTok) mais n'est pas chiffrée |
| Listes de « mots puissants » | Aucune recherche | Concret, chiffres vrais, « tu » |
